# Initial checks of RTX 5090 model parameters

The research question is whether realistic GPU kernel optimization can be expressed and solved efficiently as a mixed-integer program. This first pass checks the provisional hardware values that support that formulation. A relevant source, measurement, or informed comparison is sufficient to retain a provisional value; exact recovery of private circuitry is not required.

The original inventory contains 134 functional and timing entries. Of these, 118 currently use assumption-based baselines. The table also retains 17 recorded capacities and configuration values, so all 151 entries remain visible.

A supporting check can concern only part of an entry. A numerical model test supports functional consistency, while a timing experiment supports its measured execution path. Neither automatically supports an intrinsic hardware latency or hidden queue depth. Entries with no supporting check remain explicitly marked.
